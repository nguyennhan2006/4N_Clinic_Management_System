\section{Biến môi trường backend}

File \code{backend/.env.example} được copy thành \code{backend/.env}. Các biến quan trọng gồm database URL, JWT access secret, JWT refresh secret và port backend.

\begin{lstlisting}[language=bash,caption={Ví dụ biến môi trường backend}]
DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/clinic_db?schema=public"
JWT_ACCESS_SECRET="change_me_to_a_random_secret"
JWT_ACCESS_EXPIRES="1d"
JWT_REFRESH_SECRET="change_me_to_another_random_secret"
JWT_REFRESH_EXPIRES="7d"
PORT=3000
\end{lstlisting}

\section{Cài đặt và chạy backend}

\begin{lstlisting}[language=bash,caption={Cài đặt và chạy backend}]
git clone <repository-url>
cd 4N_Clinic_Management_System
cd backend
npm install
cp .env.example .env
# Fill DATABASE_URL, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET
npx prisma migrate dev
npx prisma db seed
npm run start:dev
\end{lstlisting}

Sau khi chạy thành công:

\begin{itemize}
    \item Backend: \code{http://localhost:3000}
    \item API prefix: \code{http://localhost:3000/api/v1}
    \item Swagger UI: \code{http://localhost:3000/api/docs}
\end{itemize}

\section{Cài đặt và chạy frontend}

\begin{lstlisting}[language=bash,caption={Cài đặt và chạy frontend}]
cd frontend
npm install
echo "VITE_API_BASE_URL=http://localhost:3000/api/v1" > .env.local
npm run dev
\end{lstlisting}

Sau khi chạy thành công, frontend truy cập tại \code{http://localhost:5173}.

\section{Quản lý database}

\begin{lstlisting}[language=bash,caption={Các lệnh quản lý database}]
cd backend
npx prisma studio
npx prisma validate
npx prisma migrate dev --name <migration-name>
npx prisma migrate reset
\end{lstlisting}

\section{Lệnh kiểm tra chất lượng code}

\begin{lstlisting}[language=bash,caption={Các lệnh kiểm tra build, lint và test}]
# Backend
cd backend
npm run build
npm run lint
npm run test
npm run test:e2e

# Frontend
cd frontend
npm run build
npm run lint
\end{lstlisting}

Các lệnh trên cần được nhóm chạy thực tế và chụp log kết quả trước khi nộp báo cáo. Riêng \code{npm run test:e2e} cần database thật và dữ liệu test phù hợp.

\section{Troubleshooting khi triển khai local}

\begin{longtable}{|p{4cm}|p{5cm}|p{5.2cm}|}
\caption{Một số lỗi thường gặp khi chạy local}\\
\hline
\textbf{Vấn đề} & \textbf{Nguyên nhân thường gặp} & \textbf{Cách xử lý} \\
\hline
Backend không kết nối được database & Sai \code{DATABASE\_URL}, PostgreSQL chưa chạy hoặc database chưa tạo & Kiểm tra service PostgreSQL, tạo database, cập nhật \code{backend/.env}, chạy \code{npx prisma validate}. \\
\hline
Prisma migrate lỗi & Schema chưa đồng bộ hoặc migration cũ bị lệch với database local & Sao lưu dữ liệu cần thiết, chạy \code{npx prisma migrate dev}; nếu là môi trường demo có thể dùng \code{npx prisma migrate reset}. \\
\hline
Frontend gọi API lỗi CORS/Network & Backend chưa chạy, sai \code{VITE\_API\_BASE\_URL} hoặc port backend khác 3000 & Kiểm tra backend tại \code{/api/docs}, cập nhật \code{frontend/.env.local}. \\
\hline
Đăng nhập thất bại với tài khoản seed & Chưa chạy seed hoặc password seed không khớp & Chạy \code{npx prisma db seed}, kiểm tra lại danh sách tài khoản demo. \\
\hline
Test e2e fail do dữ liệu cũ & Database test còn dữ liệu từ lần chạy trước & Reset database test hoặc dùng seed/test setup sạch trước khi chạy \code{npm run test:e2e -- --runInBand}. \\
\hline
\end{longtable}

\section{Ghi chú vận hành production trong tương lai}

Dự án chưa có cấu hình production. Nếu triển khai production trong tương lai, nhóm cần bổ sung:

\begin{itemize}
    \item Dockerfile và docker-compose hoặc phương án container hóa tương đương.
    \item CI/CD pipeline để build, lint, test tự động.
    \item HTTPS, CORS chặt chẽ, secret đủ mạnh và rotation policy.
    \item PostgreSQL connection pooling, backup database và monitoring.
    \item Quy trình deploy frontend production build qua Nginx/CDN hoặc hosting phù hợp.
\end{itemize}
