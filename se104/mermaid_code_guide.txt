# 08. Sequence Login / JWT Authentication

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant FE as Frontend Login Page
    participant AC as AuthController
    participant AS as AuthService
    participant US as UsersService
    participant DB as PostgreSQL
    participant JWT as JWT Token Generator

    User->>FE: Enter email + password
    FE->>AC: POST /auth/login
    AC->>AS: login(dto)

    AS->>US: findByEmail(email)
    US->>DB: SELECT user by email
    DB-->>US: user record / null
    US-->>AS: user

    alt Invalid email or inactive user
        AS-->>AC: UnauthorizedException
        AC-->>FE: 401 Unauthorized
        FE-->>User: Show login error
    else Password verification
        AS->>AS: Compare password hash

        alt Wrong password
            AS-->>AC: UnauthorizedException
            AC-->>FE: 401 Unauthorized
            FE-->>User: Show "Email hoặc mật khẩu không đúng"
        else Valid credentials
            AS->>JWT: Sign access token
            JWT-->>AS: accessToken
            AS->>JWT: Sign refresh token
            JWT-->>AS: refreshToken
            AS->>DB: Store refresh token hash / session
            DB-->>AS: saved
            AS-->>AC: tokens + user info
            AC-->>FE: 200 OK
            FE->>FE: Store token and bootstrap session
            FE-->>User: Redirect to dashboard
        end
    end

    Note over AS,JWT: Stateless API authentication<br/>Access token for API calls<br/>Refresh token for renewal/revoke
```

# 09. Sequence Create Visit

```mermaid
sequenceDiagram
    autonumber
    actor Receptionist
    participant FE as Frontend Visit Page
    participant VC as VisitsController
    participant VS as VisitsService
    participant RS as RegulationsService
    participant DB as PostgreSQL

    Receptionist->>FE: Select patient and click Create Visit
    FE->>VC: POST /visits {patientId, visitDate}
    VC->>VS: createVisit(dto, currentUser)

    VS->>DB: SELECT Patient by id
    DB-->>VS: patient / null

    alt Patient not found
        VS-->>VC: NotFoundException
        VC-->>FE: 404 Not Found
    else Patient exists
        VS->>DB: SELECT Visit WHERE patientId AND visitDate
        DB-->>VS: existing visit / null

        alt Duplicate same-day visit
            VS-->>VC: ConflictException
            VC-->>FE: 409 Conflict
            FE-->>Receptionist: Show duplicate visit error
        else No duplicate
            VS->>RS: getActive(MAX_PATIENTS_PER_DAY)
            RS->>DB: SELECT active regulation
            DB-->>RS: quota value / default
            RS-->>VS: maxPatientsPerDay

            VS->>DB: COUNT visits by date
            DB-->>VS: count

            alt Quota exceeded
                VS-->>VC: ConflictException
                VC-->>FE: 409 Conflict
                FE-->>Receptionist: Show quota exceeded error
            else Valid request
                VS->>DB: SELECT MAX(queueNumber) for visitDate
                DB-->>VS: lastQueueNumber
                VS->>VS: nextQueueNumber = last + 1
                VS->>DB: INSERT Visit status = WAITING
                DB-->>VS: created Visit
                VS-->>VC: VisitDTO
                VC-->>FE: 201 Created
                FE-->>Receptionist: Show success and update waiting list
            end
        end
    end

    Note over VS,DB: Business rules:<br/>1. No duplicate same-day visit<br/>2. Daily quota check<br/>3. Auto queue number
```

# 12. Sequence FEFO Dispensing

```mermaid
sequenceDiagram
    autonumber
    actor Pharmacist
    participant FE as Frontend Pharmacy Page
    participant PC as PharmacyController
    participant PS as PharmacyService
    participant IS as InventoryService
    participant DB as PostgreSQL

    Pharmacist->>FE: Open prescription and click Dispense
    FE->>PC: POST /pharmacy/dispenses {prescriptionId}
    PC->>PS: dispensePrescription(prescriptionId, pharmacistId)

    PS->>DB: SELECT Prescription + PrescriptionItems
    DB-->>PS: prescription items

    loop For each prescription item
        PS->>IS: allocateLots(drugId, quantity)
        IS->>DB: SELECT StockLot WHERE quantityOnHand > 0 ORDER BY expiryDate ASC
        DB-->>IS: lots sorted by expiryDate

        alt Insufficient stock
            IS-->>PS: BadRequestException
            PS-->>PC: 400 Insufficient stock
            PC-->>FE: Error response
            FE-->>Pharmacist: Show insufficient stock
        else Enough stock
            IS->>IS: Allocate from earliest expiry first
            IS-->>PS: lot allocations
        end
    end

    alt All items allocated
        PS->>DB: Transaction begin
        PS->>DB: INSERT Dispense
        loop Each allocated lot
            PS->>DB: INSERT DispenseItem
            PS->>DB: UPDATE StockLot.quantityOnHand
            PS->>DB: INSERT StockMovement type = DISPENSE
        end
        PS->>DB: Commit transaction
        DB-->>PS: committed
        PS-->>PC: DispenseDTO
        PC-->>FE: 201 Created
        FE-->>Pharmacist: Show dispense success
    end

    Note over IS,DB: FEFO = First Expired, First Out<br/>Use earliest expiryDate stock lot first
```
