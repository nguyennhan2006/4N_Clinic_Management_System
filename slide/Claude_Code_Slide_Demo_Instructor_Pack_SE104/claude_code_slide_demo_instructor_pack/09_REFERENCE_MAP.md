# REFERENCE MAP - SOFTWARE ENGINEERING 10E

Dùng tài liệu Ian Sommerville, *Software Engineering*, 10th Edition làm cơ sở khái niệm, không dùng để thay thế bằng chứng dự án.

- Chương 1: phần mềm chuyên nghiệp và thuộc tính chất lượng.
- Chương 2: software process, bốn hoạt động specification-development-validation-evolution; waterfall, incremental và reuse-oriented process.
- Chương 3: Agile, user stories, test-first, refactoring, Scrum và điều kiện áp dụng.
- Chương 4: elicitation, specification, validation và requirements change.
- Chương 5: context, interaction, structural và behavioral models.
- Chương 6: architectural decisions, views và patterns.
- Chương 7: object-oriented design, design patterns và implementation issues.
- Chương 8: development testing, release testing và user/acceptance testing.
- Chương 22: risk management, managing people và teamwork.
- Chương 23: planning, scheduling, milestones, agile planning và estimation.
- Chương 24: quality plans, standards, reviews/inspections và measurement.
- Chương 25: version management, system building, change management và release management.

Nguyên tắc áp dụng: thuật ngữ và mô hình từ giáo trình giúp giải thích dự án; kết luận về dự án phải đến từ code, tài liệu, test và lịch sử thực tế.
