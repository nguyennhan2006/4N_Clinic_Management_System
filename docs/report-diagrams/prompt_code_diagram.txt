Được. Tôi chuyển sang hướng **PlantUML source code**, không dùng Gemini tạo ảnh nữa. Các sơ đồ dưới đây bám theo tư duy chuẩn của Software Engineering: đặc tả yêu cầu, mô hình hệ thống, kiến trúc, thiết kế dữ liệu/xử lý/giao diện, hiện thực, kiểm thử và triển khai; đây cũng là các nhóm hoạt động chính trong quy trình phần mềm và mô hình hóa hệ thống theo Sommerville.

actor Pharmacist

  Pharmacy -> Inventory : allocateLots(drugId, quantity)
  activate Inventory
  Inventory -> DB : SELECT StockLot\nWHERE drugId AND quantityOnHand > 0\nORDER BY expiryDate ASC
  DB --> Inventory : lots sorted by expiryDate

    Inventory --> Pharmacy : throw BadRequestException
    Pharmacy --> Controller : 400 Insufficient stock
    Controller --> FE : Error response
    FE --> Pharmacist : Show insufficient stock
  else Enough stock
    Inventory -> Inventory : Allocate from earliest expiry first\nFEFO = First Expired, First Out
    Inventory --> Pharmacy : lot allocations
  end
  deactivate Inventory
end

alt All items allocated
  Pharmacy -> DB : Transaction begin
  Pharmacy -> DB : INSERT Dispense
  loop Each allocated lot
    Pharmacy -> DB : INSERT DispenseItem
    Pharmacy -> DB : UPDATE StockLot.quantityOnHand
    Pharmacy -> DB : INSERT StockMovement(type=DISPENSE)
  end
  Pharmacy -> DB : Commit transaction
  DB --> Pharmacy : committed
  Pharmacy --> Controller : DispenseDTO
  Controller --> FE : 201 Created
  FE --> Pharmacist : Show dispense success
end

deactivate Pharmacy
deactivate Controller

note bottom
FEFO protects clinic inventory:
drug lots with the earliest expiry date are consumed first.
end note
