# Error Codes

## 1. Mục tiêu

Chuẩn hóa error code để:

- frontend hiển thị thông báo đúng;
- backend dễ debug;
- team dễ review nghiệp vụ.

---

## 2. Auth

- `INVALID_CREDENTIALS`
- `USER_INACTIVE`
- `USER_LOCKED`
- `REFRESH_TOKEN_INVALID`
- `UNAUTHORIZED`
- `FORBIDDEN`

---

## 3. Patient

- `PATIENT_ALREADY_ARCHIVED`
